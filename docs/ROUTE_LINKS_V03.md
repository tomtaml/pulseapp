# v0.3 route link templates

Use the Cloudflare preview hostname for `prototype-v0.3` as `BASE_URL`.

## Finland fleet

`BASE_URL/?variant=fi-fleet&workshop=TAMPERE-S4&demo=1`

## Finland citizen / accessibility

`BASE_URL/?variant=fi-citizen&workshop=TAMPERE-S4&demo=1`

The `demo=1` parameter guarantees the participant-facing completion message states that no research data were sent. Repository defaults also keep collection disabled.
